# Free Consumer Rights & Dispute Templates Kit

Fillable, printable templates for common consumer-rights paperwork: demand letters, warranty claims, small-claims worksheets, and a complaint tracker. No account needed. Open the HTML files in any browser, fill them in, and print (or save to PDF). Edit the Markdown sources to tailor the language to your situation.

## What's inside

| Template | Markdown | Printable HTML |
|---|---|---|
| Demand letter | `templates/demand-letter.md` | `html/demand-letter.html` |
| Warranty claim form | `templates/warranty-claim.md` | `html/warranty-claim.html` |
| Small-claims worksheet | `templates/small-claims-worksheet.md` | `html/small-claims-worksheet.html` |
| Complaint tracker | `templates/complaint-tracker.md` | `html/complaint-tracker.html` |

## How to use

1. Pick a template.
2. Open the `.html` file in your browser (double-click it; no server or account required).
3. Fill in the highlighted fields.
4. Print, or choose "Save as PDF" from your browser's print dialog.
5. Keep copies of everything you send and send disputes by certified mail with return receipt when possible.

The Markdown files (`templates/`) are the source text — copy, edit, and re-export them however you like.
